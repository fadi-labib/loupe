*[CRA]: EU Cyber Resilience Act. Regulation 2024/2847. Fully applicable December 2027.
*[STRIDE]: Microsoft's threat-modelling categorisation: Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege.
*[SBOM]: Software Bill of Materials. CycloneDX is the format Loupe uses.
*[CycloneDX]: SBOM format standard. Loupe uses 1.6 JSON. cyclonedx.org.
*[OpenVEX]: Vulnerability EXploitability eXchange — open format for per-CVE impact statements. openvex.dev.
*[VEX]: Vulnerability EXploitability eXchange — per-CVE impact statements. OpenVEX is the standard.
*[CVE]: Common Vulnerabilities and Exposures — public catalogue of disclosed security flaws.
*[CWE]: Common Weakness Enumeration — taxonomy of software-weakness types.
*[CAPEC]: Common Attack Pattern Enumeration and Classification.
*[CVSS]: Common Vulnerability Scoring System — 0.0-10.0 base-score severity.
*[SAST]: Static Application Security Testing — analysing source without running it.
*[MCP]: Model Context Protocol — Anthropic-originated JSON-RPC protocol for LLM tool/resource exposure.
*[PydanticAI]: Multi-provider LLM agent framework Loupe is built on. By the Pydantic team.
*[VCR]: pytest-vcr. Records HTTP fixtures once, replays forever. Loupe uses it for LLM-involving integration tests.
*[ADR]: Architecture Decision Record. Loupe's decisions log uses this style.
*[LINDDUN]: Privacy threat-modelling methodology (Linkability, Identifiability, Non-repudiation, Detectability, Disclosure, Unawareness, Non-compliance).
*[TARA]: Threat Analysis and Risk Assessment. ISO/SAE 21434's term (automotive cybersecurity).
*[HARA]: Hazard Analysis and Risk Assessment. ISO 26262's term (functional safety).
*[DPIA]: Data Protection Impact Assessment. GDPR's term.
*[ThreatLens]: Loupe's v1 lens. STRIDE-based threat modelling.
*[Loupe]: The platform. Named after the precision inspection lens.
*[PR]: Pull Request — GitHub's term for a proposed change.
*[CI]: Continuous Integration.
*[SHA-256]: Secure Hash Algorithm, 256-bit variant. Used for run-record hash chains.
*[PII]: Personally Identifiable Information.
*[LLM]: Large Language Model.
*[REPL]: Read-Eval-Print Loop. Interactive shell.
*[YAGNI]: You Aren't Gonna Need It — engineering heuristic against speculative abstraction.
*[CODEOWNERS]: GitHub file listing required reviewers per path.
*[OG]: Open Graph — social-media preview metadata.
*[OSV]: Open Source Vulnerabilities database from Google.
*[NVD]: National Vulnerability Database (NIST).
*[GHSA]: GitHub Security Advisories.
*[EPSS]: Exploit Prediction Scoring System (FIRST).
