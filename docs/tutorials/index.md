# Tutorials

Guided learning paths. Each tutorial walks through an end-to-end scenario so you build a mental model of how Loupe feels in practice.

The canonical entry point is the [Quickstart](../quickstart.md), which lives at the top level because it's the one tutorial every new user runs first. Additional tutorials land here as they're written — for example, walkthroughs that cover a specific deployment shape (monorepo, offline, GitLab) or a specific lens end-to-end.

If you already know Loupe and just want to accomplish a specific task, check [how-to](../how-to/index.md) instead.
